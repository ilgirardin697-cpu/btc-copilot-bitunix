# Single-segment Kill Zones visual prototype

Offline research. **SHADOW ONLY. TRADE AUTHORITY: NONE.** No network or orders.
See [SPEC_V1](SPEC_V1.md) for the ONE chosen hypothesis and its limitations.

Open [the gallery](examples/index.html) to see the boxes, one original segment,
one translated copy, the extension used as trigger, and confirmation / reference
entry / structural SL where they exist. In an ambiguous case only the boxes are
drawn. Artificial controls are labelled **NOT BTC / NOT HISTORICAL EVIDENCE**.

Python 3.12+. Calculations/rendering are stdlib, with IANA timezone data required.
Windows: install `tzdata==2026.6` in an isolated environment; a previously existing
environment with that version was used locally. No production environment changed.

```sh
python -m unittest research.kill_zones_visual_v1.test_prototype -v
python -m research.kill_zones_visual_v1.build_visuals
python -m research.kill_zones_visual_v1 \
  --csv research/kill_zones_visual_v1/examples/BTCUSDT_USDM_1h_20260901_03.csv \
  --manifest research/kill_zones_visual_v1/examples/data_manifest.json \
  --day 2026-09-03 --as-of 2026-09-04T00:00:00Z --out research/cache/visual_v1
```

The manifest's excerpt hash is verified by the CLI. Its venue declaration is
provenance metadata, not independent authentication of an arbitrary input file.
The checked-in excerpt was generated by `prepare_example.py` from the previously
cached official Binance Vision ZIP, matched against its saved official checksum.
No source strategy, simulation, results or data loader from PR #40 is imported.
To reproduce the extraction with an already downloaded archive:

```sh
python -m research.kill_zones_visual_v1.prepare_example \
  --archive /local/public/bars-2026-09.zip \
  --checksum /local/public/bars-2026-09.checksum \
  --out research/kill_zones_visual_v1/examples
```

The ZIP URL and SHA256 are in [data_manifest.json](examples/data_manifest.json).
Only 72 closed public 1H bars are versioned, not the raw month. Public historical
market data are reused solely for visual/temporal checks, not an independent test.

The local worktree directory may itself be under `research/cache`, but everything
here is **tracked in a separate Git branch at `research/kill_zones_visual_v1/`**.
It is not an unversioned cache artifact. Nothing imports this package from runtime.

No daemon, scheduler, activation flag, Telegram route, private API, execution,
position sizing, PnL simulator or automatic forward collector is included.
This is the drawing/causality phase; subsequent evaluation requires its own fixed
cost/exit assumptions. No claim of edge or exact original-method parity.
